Auto-advance AGENT-LED steps (Full / Most / Checkpoint)

F011 lets you pick how much auto-advancement the framework does for AGENT-LED steps in SPEC + SHIP phases. Three tiers trade speed against safety. Full auto-advances every step where the action says it doesn't need your approval. Most does the same, except destructive actions (mark-shipped, manifest repins, branch deletions, append-only edits) still prompt. Checkpoint is today's behaviour — prompt every step. Default is Checkpoint, so existing projects don't change unless you opt in. Pairs with F008 (multi-model) + F010 (parallel waves) to deliver the drop-the-brief-walk-away shape.

Example interactions

Three concrete walks showing how the user picks a tier and what /next does under each.

/sdd-setup
(wizard reaches the automation-level brick) "Automation level for AGENT-LED steps — Full / Most / Checkpoint?"
