02

Logo · three directions

CONCEPT A
The plumb-bob

Most literal + iconic. Hairline string + weighted teardrop. Single accent dot at the tip = the AI in plumb. Scales to favicon (just the bob) and stencil prints great.

CONCEPT B
Vertical + dot

Abstracted plumb-bob. Pure vertical bar (true alignment) + single accent dot below (the weight). Pairs with a wordmark like a typographic colon. Works as a UI status pip.

CONCEPT C
The crosshair

Engineering precision. Circle + true vertical + dashed horizontal (the level). Centre dot = your spec. Modern, dynamic, slightly playful. Reads as both target + spirit-level.

📐 Sam's pick goes to a vector designer for refinement · All three work mono + on dark/light surfaces

06

Voice · three rules

①
Anti-hype.

No "revolutionary." No "supercharge." No rocket emojis (sorry). Plumb is quiet competence — the verb form would be "to align," not "to disrupt."

②
One sentence per claim.

If you can't say it in 12 words, you don't yet know what it does. Long copy = wishy-washy thinking.

③
Receipts always.

Every claim shows the mechanism. Not "Plumb prevents drift" — "Plumb's pre-commit hook re-runs verify-stage on every commit and refuses if the result doesn't match what was approved."

07

Don't ·

✗ Use gradients on the bob (it's a single weight)
✗ Pair with a second accent colour
✗ Stack the wordmark + mark vertically (always horizontal lockup)
✗ Use the bob without the string in body text (string is the metaphor)
✗ Italicise the wordmark
✗ Write taglines longer than 5 words
